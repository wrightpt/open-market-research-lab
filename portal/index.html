04 / AGENT WORKFLOWS

Bring the coding agent you already use.

Agents work on the same public Git repository. No Kubernetes token, remote MCP server, or direct database access is necessary for the current benchmark.

Claude CodeCOPY & PASTE

Open Claude Code in your cloned checkout and give it this bounded task:

Read AGENTS.md and DATA_POLICY.md. Verify the synthetic fixture hashes and run all unit tests. Review the baseline for lookahead leakage or incorrect fill-cost accounting. Report a minimal failing synthetic test, if any. Never use private systems or evaluate holdout outcomes.
CodexCOPY & PASTE

Run Codex interactively from your cloned checkout with this request:

Read AGENTS.md. Validate the deterministic data manifest and baseline submission. Run the repository tests. Audit causal-prefix invariance and next-open gap execution. Suggest a focused regression test only; do not call external APIs, access credentials or score the public holdout.
OpenCodeCOPY & PASTE

Open OpenCode within the repository and ask it to inspect the same evidence:

Inspect AGENTS.md, docs/ARCHITECTURE.md and DATA_POLICY.md. Execute the local synthetic verification and test suite. Check missing-value propagation, cost reconciliation and the experiment evidence contract. Provide a small reviewable PR with tests if you find a bug. No production access or unapproved data.
