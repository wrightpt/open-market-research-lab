03 / developer reference

One contract.
Seven research tools.

A bounded HTTPS interface shared by API clients and the local stdio adapter. Authorization and query limits belong to the backend.

Integration status

The seven research tool paths are agreed. Configure an approved HTTPS API origin privately; no origin or credential is embedded in this UI.

Offline quickstart

Python 3.11+ · standard library · no account required

python3 -m market_lab verify-data
python3 -m market_lab validate submissions/baseline.json
python3 -m unittest discover -s tests -v
python3 -m market_lab backtest submissions/baseline.json

No holdout evaluation is needed for onboarding.

05 / challenge 001

Can deterioration
be seen in time?

When spreads widen, depth shrinks, and open interest falls, does a causally timed alert precede a drawdown—or only tell us what already happened?

Bring a reproducible critique.

The baseline uses scripted liquidity and deleveraging scenarios. It includes false alarms, missing observations, unwarned shocks, and late warnings. Success on these fixtures cannot establish a market edge.

  • Prove a future-data leak with a minimal prefix example.
  • Reconcile next-open fills and both transaction costs.
  • Check denominator treatment for unavailable outcomes.
  • Preserve exact identities and every development trial.
